# Node.js to Go Equivalents

| Node / TypeScript | Go equivalent |
|-------------------|---------------|
| Node.js | Go |
| Express | Gin |
| Prisma | GORM or sqlc |
| Prisma migrations | GORM migrations / Goose / Atlas |
| bcrypt | `golang.org/x/crypto/bcrypt` |
| jsonwebtoken | `github.com/golang-jwt/jwt/v5` |
| Zod | `go-playground/validator` or `ozzo-validation` |
| dotenv | `godotenv` or environment variables |
| PostgreSQL | `pgx` |
| Redis | `go-redis` |
| Jest/Vitest | Go's built-in `testing` |
| Supertest | `httptest` |
| Pino/Winston | Go `slog` |
| BullMQ | Asynq / River |
| Socket.IO | WebSocket libraries such as `gorilla/websocket` or `nhooyr/websocket` |
